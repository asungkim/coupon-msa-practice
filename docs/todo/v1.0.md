# Phase 1. 기본 기능 구현

## 🔹 Epic: 엔티티 및 기반 구조

- ✅ User 엔티티 + Repository
- ✅ Coupon 엔티티 + Repository
- ✅ CouponIssue 엔티티 + Repository + IssueStatus Enum
- ✅ 예외 클래스 정의 (UserNotFound, CouponNotFound, CouponAlreadyIssued, CouponOutOfStock, CouponNotAvailable, InsufficientPoints)
- ✅ 글로벌 예외 핸들러

## 🔹 Epic: 셋업 API

- ✅ POST `/api/users` — 유저 생성 (Controller, UserService)
- ✅ POST `/api/users/{userId}/points` — 포인트 충전 (Controller, UserService)
- ✅ PointService — 포인트 차감 로직 (쿠폰 발급 시 CouponService에서 호출)
- ✅ POST `/api/coupons` — 쿠폰 생성 (Controller, CouponService)

## 🔹 Epic: 쿠폰 발급

- ✅ CouponService — 쿠폰 발급 로직 (검증 → PointService.decreasePoints → 재고 차감 → 발급 이력 저장)
- ✅ POST `/api/coupons/{couponId}/issue` — 발급 API (Controller)
- ✅ PushNotificationClient — 알림 서버 연동 (트랜잭션 내 동기 호출)

## 🔹 Epic: 테스트

- ⚪ 단위 테스트 (엔티티 비즈니스 로직)
- ⚪ 통합 테스트 (발급 API 정상/실패 케이스)
- ⚪ 부하 테스트 (CouponLoadTest — 200명 동시 발급, 문제 확인용)
